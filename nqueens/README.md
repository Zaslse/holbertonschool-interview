# N Queens

This project solves the N Queens puzzle using backtracking.

## Description

The goal is to place N queens on an N x N chessboard
so that no two queens attack each other.

## Usage

python3 0-nqueens.py N

N must be an integer greater than or equal to 4.

## Algorithm

The program places one queen in each row and checks
columns and diagonals to avoid conflicts.

It uses backtracking to find and print every valid solution.
