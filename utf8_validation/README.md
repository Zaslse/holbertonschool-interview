# UTF-8 Validation

This project implements UTF-8 encoding validation in Python.

## Task 0: UTF-8 Validation

File: `0-validate_utf8.py`

The `validUTF8(data)` function checks whether a list of integers
represents valid UTF-8 encoding using the 8 least significant bits
of each integer.

Returns `True` for valid UTF-8 and `False` otherwise.
